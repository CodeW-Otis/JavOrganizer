Throughput

Speed & politeness

How hard the engine works the sites. The defaults are polite; raise them only if your setup tolerates more traffic.

videos

Videos scraped at the same time during scans. Default 4; capped at 32.

sites

Enabled sites scraped at once per video, richest first. Default 8. More sites = fuller metadata and fewer requests per single site.

ms

Minimum pause between requests to the same site, randomly jittered. Default 500; 0 disables.

Storage

Cache

Scraped records are kept on disk so scans stay cheap and the sites are not asked twice.

hours

How long a scraped video stays fresh before the next scan re-fetches it. Default 720 (30 days); 0 disables expiry.

hours

How long an unmatched code is remembered so re-scans skip it. Default 168 (7 days); 0 disables.

Library cards

Collections

A daily task organizes the scraped library into browse cards — one per person, with their photo as the poster, plus ranked Most Viewed / Most Liked collections.

videos

A person gets their own collection only when they appear in at least this many scraped videos. Default 2.
